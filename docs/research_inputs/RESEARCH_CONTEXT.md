# Public research context

This neutral retrospective summary replaces the inherited multi-project dossiers. Originals are preserved in an excluded private evidence folder. Historical novelty assertions are unverified and are not adopted here.

The pilot asks whether fixed selective decoding preserves command recall under participant, session and proxy electrode shifts. The corrected result is descriptive and negative. Broader novelty, clinical usefulness and matched-recall superiority remain unestablished.

## Resolved primary references

- [EMGBench: Benchmarking Out-of-Distribution Generalization and Adaptation for Electromyography](https://arxiv.org/abs/2410.23625) provides the nearest broad comparison context.
- [A generic non-invasive neuromotor interface for human-computer interaction](https://doi.org/10.1038/s41586-025-09255-w) provides related neuromotor decoding context. Its excluded data are not used.

# Neutral gate review B

Retrospective public summary of the MyoShift section of a second inherited gate review. Internal attribution, tracking parameters and unrelated portfolio assertions are omitted; the exact original remains excluded privately. Recommendations are historical proposals, not completed validation.

The review proposed a narrowly scoped command-event benchmark with grouped participant/session splits, purged overlap, abstention and hysteresis comparisons. [EMGBench](https://arxiv.org/abs/2410.23625) is existing broad out-of-distribution evaluation work, so a general benchmark novelty claim is unestablished.

The completed subset uses [GRABMyoFlow](https://doi.org/10.13026/ah52-zq51). The corrected pilot retains a fixed hysteresis reference and descriptive participant-cluster intervals. A tuned-controller comparison, threshold frontier, physical electrode displacement and secondary-dataset replication remain untested.
